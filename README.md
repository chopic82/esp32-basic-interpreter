# ESP32 BASIC Interpreter

Ретро-компьютер на ESP32: интерпретатор языка BASIC с веб-интерфейсом, Telnet-консолью, графикой и поддержкой кириллицы (UTF-8).

## 🚀 Возможности
*   **Язык BASIC**: переменные, массивы (1D и 2D), строки (UTF-8), циклы (`FOR/NEXT`), условия (`IF/THEN`), переходы (`GOTO`).
*   **Математика**: `+ - * / ^ MOD`, `SIN`, `COS`, `SQR`, `ABS`, `INT`, `RND`, `VAL`.
*   **Строковые функции**: `LEN`, `MID$`, `ASC`, `CHR$`.
*   **Графика**: линии, прямоугольники, круги, дуги, эллипсы, текст, заливка (`TFT_eSPI` + ILI9488).
*   **Веб-интерфейс**: загрузка программ, виртуальная клавиатура, кнопка STOP, окно `INPUT`.
*   **Telnet-консоль**: полноценная работа через PuTTY.
*   **Пагинация**: автоматическая остановка при заполнении экрана.

## 🛠️ Аппаратное обеспечение
*   ESP32 (любая плата с достаточным объемом памяти)
*   Дисплей ILI9488 (480x320) по SPI

## 📦 Программное обеспечение
*   Arduino IDE
*   Библиотеки: `TFT_eSPI`, `WebServer`, `LittleFS` (в будущем)

## ⚙️ Настройка
1.  Склонируйте репозиторий.
2.  Создайте файл `secrets.h` в папке со скетчем и добавьте туда ваши данные Wi-Fi:
    ```cpp
    #define WIFI_SSID "Ваш_SSID"
    #define WIFI_PASSWORD "Ваш_Пароль"

Настройте User_Setup.h в библиотеке TFT_eSPI под ваш дисплей.

Прошейте ESP32.

📝 Использование
Веб-интерфейс: откройте браузер и введите IP-адрес ESP32 (показан на экране дисплея после загрузки).

Telnet: подключитесь через PuTTY (Telnet, порт 23).
